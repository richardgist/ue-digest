    UE 5.8 MegaLights 性能清单：固定采样预算、方向光默认关闭与可调 CVar

    按 UE 5.8 生产就绪口径整理 MegaLights：每像素固定采样预算，灯再多时帧时相对稳定，但重要灯竞争同一像素时噪声/质量会掉。方向光需显式开 r.MegaLights.DirectionalLights，Epic 更推荐强太阳用 Deferred+VSM；诊断用 light finder / ray visualizer，并对比整帧 GPU 而不只看单个事件。给出 Allow、DownsampleMode、NumSamplesPerPixel、逐灯 Shadow Method 等缩放杠杆。

AMD FSR SDK 2.4：ML 超分覆盖 RX 6000 / 部分 Ryzen APU，并补齐 Vulkan

AMD 于 2026-10-28 发布 FSR “Redstone” SDK 2.4。ML 超分 FSR Upscaling 4.1.2 在既有 RX 9000（FP8）与 RX 7000（INT8）之外，把完整 INT8 模型扩到 RX 6000（RDNA 2）离散卡，以及 Ryzen AI Max 300/400（Strix Halo / Gorgon Halo）；另提供体积不到一半的轻量 INT8 模型给更受限的 Ryzen AI 9 300/400、Z2 Extreme、Z2 A 等 APU，模型按硬件自动选择。本版首次让 Upscaling 与 Frame Generation 在 Vulkan 上与 DirectX 12 功能对等（Ray Regeneration / Radiance Caching 仍仅 DX12）。Frame Generation (Swapchain) 4.0.0 在 RX 9000 + Adrenalin 26.10.1 等条件下可走 Driver-Assisted Frame Pacing；Ray Regeneration 1.2.1 增加独立 AO / specular occlusion 降噪。原文注明当前 UE 插件仍是 Upscaling 4.1.1 / FG 4.0.1，稍后才会跟到 4.1.2 / 4.0.2。厂商演示帧率与画质对比未在本机复现。
