BiteTheBytes unveils World Creator 4

Jim Thacker 报道:BiteTheBytes 公布 World Creator 4(接在 2026.4 之后),预计 2026 年 11 月发布。核心架构换成基于 Cloddy SDK 的 GPU 行星级地形管线,可从常规地形扩到整颗行星并导出贴球用的高度/分布数据;演示提到基于约 9GB USGS DEM 的火星数据可在软件内实时浏览。新增节点式地形编辑(与原有图层并存)、直接 heightfield 雕刻、新侵蚀/水沙沉积模型与 110+ 噪声类型;新增多边形实时渲染器(与原有 path tracer 并存),两者都支持 DLSS 4.5;还有批处理、内置 MCP 服务器(可用 Claude/ChatGPT 等外部 AI 控制),并计划首次支持 macOS 与 Linux(Linux 目标赶上首发)。当前稳定版仍是 Windows 的 2026.4,有 Blender/C4D/Godot/Houdini/Unity/Unreal 插件。价格未宣布变更。

    Hot Reload Live — free & open source C# hot reload for Godot 4 (.NET)

    社区开发者发布的 MIT 开源工具,面向 Godot 4.7+ 的 .NET 版本。它监视 C# 源文件,在独立的 AssemblyLoadContext 里编译,并用 Harmony 打补丁替换方法体,保存后下一帧就运行新代码、不必重启游戏;支持静态/实例/泛型方法以及 async 和迭代器。字段布局变化、新增字段或方法、改签名时会检测到并跳过,仍需重启;只在编辑器内生效,不进入发布版本;需要 .NET 8 SDK,不支持 GDScript。这是作者自己的介绍,我们没有实际试用。
