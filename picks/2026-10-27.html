Unity CLI 1.0.0-beta.14：无人值守打开与脚本退出码契约

游戏开发工具

Unity 员工帖宣布 CLI 1.0.0-beta.14：1.0 前敲定输出与退出码；原统一 exit 6 拆成 11–14（非项目/无 Editor/无命令/超时等）；tsv 表头与 JSON 键一致；`--timeout` 只接受整秒；状态类「否」答案 `success:false`；`unity open --until-ready/--batchmode/--accept-upgrades` 与 `terms accept` 支撑无人值守；agent 侧 `unity mcp --tools/--exclude-tools`、按 port/pid/instance 钉 Editor、`logs --console --follow`、`docs toc/--content`、`setup antigravity`。另有大量安全加固。帖下用户反馈浮动许可/`doctor --ci`、无 Hub 时 Editor 未登录等问题仍在跟进。完整细节见 `unity changelog` / docs release notes；本人未安装实测。

值得试

值得试

UE 5.8 + Sentry 插件 ≥1.24.0；开 MCP/All Toolsets 后 GenerateClientConfig；连上 agent 说用 Sentry skills 配置并打一次打包崩溃验证符号。
