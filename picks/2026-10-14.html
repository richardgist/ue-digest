DLSS 5 Comes To Hogwarts Legacy & RTX Spark, Powered By 2X Faster Model

NVIDIA GeForce News发布:2026-10-13
图形渲染前沿

NVIDIA 官方更新(作者 Andrew Burnes)。DLSS 5 的 3D-Guided Neural Rendering 模型经管线优化后性能提升约 2 倍:参数量缩到约 1.18 亿(体积减约 24%),4K 显存占用约降 20%,相对 9 月版本 GPU 开销约减半,画质自称可比。更快模型将于 10 月 16 日登陆 NBA 2K27(RTX 50 / RTX Spark / GeForce NOW),官称帧率最高约 1.4×;Hogwarts Legacy 计划 11 月 5 日加入 DLSS 5,Where Winds Meet 约 11 月下旬。NVIDIA App beta 新增 Frame Generation「Preset C」性能模式(用更轻算法替代第二套光流 AI),在 RTX 5060 上官方测得最高约快 35%,画质有轻微折中;10 月 23 日 RTX Remix 也将加入同一套加速。以上为厂商自报数据与排期。

为什么有用

做实时渲染或 RTX Remix 模组时,能立刻试更轻的 Frame Generation,并跟进 Neural Rendering 的显存/开销变化。

值得试

装最新 NVIDIA App beta → Settings 勾选 Beta → Graphics 里对支持 FG 的游戏设 DLSS Override Model Presets → Frame Generation 选 Preset C,对比画质与帧率。

BiteTheBytes unveils World Creator 4

CG Channel发布:2026-10-12
游戏开发工具

Jim Thacker 报道:BiteTheBytes 公布 World Creator 4(接在 2026.4 之后),预计 2026 年 11 月发布。核心架构换成基于 Cloddy SDK 的 GPU 行星级地形管线,可从常规地形扩到整颗行星并导出贴球用的高度/分布数据;演示提到基于约 9GB USGS DEM 的火星数据可在软件内实时浏览。新增节点式地形编辑(与原有图层并存)、直接 heightfield 雕刻、新侵蚀/水沙沉积模型与 110+ 噪声类型;新增多边形实时渲染器(与原有 path tracer 并存),两者都支持 DLSS 4.5;还有批处理、内置 MCP 服务器(可用 Claude/ChatGPT 等外部 AI 控制),并计划首次支持 macOS 与 Linux(Linux 目标赶上首发)。当前稳定版仍是 Windows 的 2026.4,有 Blender/C4D/Godot/Houdini/Unity/Unreal 插件。价格未宣布变更。

为什么有用

做开放世界或关卡地形时,节点工作流 + MCP + 引擎插件这条链路,能把地形生成接到 AI 助手和批处理流水线里。

值得试

若已在用 World Creator,先列一份导出到 UE/Unity 的检查清单;等 4 出后重点试节点图、批处理和 MCP 能否驱动你现有的高度图管线。

Cursor CLI v2026.10.08: Auto-review 对危险删除更严、Skills 越界会警告

Cursor Docs · CLI changelog发布:约 2026-10-08
AI 工具效率

官方 CLI changelog 中 v2026.10.08 条目。Auto-review 现在会对递归/强制/通配/镜像类删除在目标可能「写出来和解析结果不一致」时先要批准(例如路径里有未设变量或多余空格)。`/skills` 会对超出 Agent Skills 规范的 skill 显示黄色警告计数,点开列出问题:名称超 64 字符或不符合小写连字符、frontmatter name 与文件夹不一致、description 超 1024 字符、正文约超 5000 tokens。Bedrock 自带密钥模式下可选 Claude Opus 5.5 / Sonnet 5.5。ACP 客户端在监视后台 shell 输出匹配时会真正收到唤醒(以前只说会通知却不来)。自托管 worker:any-repo 池代理在认领的 checkout 里跑工具,并避免复用留有未跟踪 rules/skills/AGENTS.md 的脏目录;注册仓库超限时直接退出并提示删多少。以上为官方说明,我们未逐项复测。

为什么有用

用 CLI Agent 写代码时,危险删路径和不合规 skill 是常见踩坑点,这版把审批和自检前置了。

值得试

跑 agent update 升到含 2026.10.08 的版本;在 /skills 看有没有黄警告;故意写一条带未展开变量的 rm -rf 路径,确认 Auto-review 会拦住。
