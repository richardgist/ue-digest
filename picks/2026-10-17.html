Budgeted-GS: Real-Time Large-Scale Gaussian Splatting via Factoring LOD

arXiv发布:2026-10-02
图形渲染前沿

论文提出对已训练 3DGS 做后处理「factoring tree」与单参数像素 footprint 调度（Factoring LOD），以及按容量地板直接训练的 Budget-Centered Training。作者称在消费级 GPU 上可对城市场景做原生 1920×1080、全 SH 实时渲染（文中举例 RTX 4080 SUPER 上约 71 fps）；性能数字为论文报告，尚未经第三方复核。

值得试

Introducing the Cesium ion MCP Server

Cesium发布:2026-10-12
游戏开发工具

Cesium 托管发布 ion MCP Server：Claude Code、Codex、Cursor、Copilot 等可通过 OAuth 直接操作 ion 账户（查找资产、查 tiling 状态、查询 BIM/CAD tiler 的 Asset Element 等），无需手写 REST。首发是 API 子集；支持写操作（上传/tiling），并要求 agent 在改数据前征求许可；官方称不会用用户数据训练模型。

为什么有用

把 3D Tiles/地球级资产接到日常 coding agent，适合做 CesiumJS 查看器、仿真或开放世界地理内容时少切浏览器。

值得试

Claude Code v2.1.302：Idle compaction 可关、fork 子 agent 默认开

GitHub anthropics/claude-code发布:2026-10-16
AI 工具效率

Claude Code v2.1.302（2026-10-16）新增 `CLAUDE_CODE_AUTO_MODE_MODEL`（仅客户端 auto mode 分类器模型）、`/config` 里 Idle compaction 开关；将 `subagent_type: "fork"` 在 `claude -p`、Agent SDK、桌面与 VS Code 默认打开（可用环境变量关掉）；桌面/VS Code 主对话子 agent 改为始终后台跑。另有大量 MCP/压缩/插件相关修复，以及多插件时启动加速。

为什么有用

长会话空闲压缩可按需关掉避免「醒来被压掉上下文」；fork 默认开让多子 agent 工作流少配一步。

值得试

`claude --version` 升到 2.1.302 后打开 `/config` 看 Idle compaction；需要时用 `CLAUDE_CODE_FORK_SUBAGENT=0` 关掉默认 fork。
