AMD FSR Upscaling 4.1.2 登陆 Xbox Series X|S（十月 GDK），首度提供主机端 ML 超分

AMD GPUOpen发布:2026-11-04
图形渲染工具

GPUOpen（厂商）称：与 Xbox 合作，把 AMD FSR Upscaling 4.1.2 随 2026 年十月 Microsoft GDK 带到 Xbox Series X|S，称这是主机端首次可用的 ML 版 FSR Upscaling；已用分析型 FidelityFX Super Resolution 的开发者可升级。Series X|S 提供 Full INT8 与更小、更便宜的 Lite INT8 两套模型（均可在 X/S 上跑），可用 GDK sample 运行时切换对比画质与开销；文称两模型 upscaler 显存相同（取决于渲染/显示分辨率而非模型），取舍是性能而非内存。集成复用与 PC 相同的 FSR SDK API（已注册开发者从 GDK 取签名二进制），输入仍为 jittered color / depth / motion vectors，质量档与 PC 一致（Native AA–Ultra Performance）。ROG Xbox Ally 系列为 Windows 设备，走标准 FSR SDK 2.4（含 Ryzen AI Z2 Extreme / Z2 A）。玩家侧需各游戏自行集成后才可用。

为什么有用

做跨主机/掌机超分时，可按同一 FSR SDK API 评估 Xbox Full/Lite INT8 与 Ally 路径，不必另起一套集成。

值得试

有 Xbox 注册：装十月 GDK，打开 AMD FSR GDK sample 对比 Full/Lite；Ally 侧用 FSR SDK 2.4 + ASUS preview driver 做对照。

Unreal Fest Tokyo：MegaLights 时代如何摆灯——RectLight 可常开、作例 160 灯约 16ms

ゲームメーカーズ（Unreal Fest Tokyo 2026 演讲报告）发布:2026-11-06
游戏开发效率

Game Makers 报道 Unreal Fest Tokyo 2026（11-03/04）演讲「MegaLightsはライティングアーティストを解放するか？」：照明督导木村洋一谈 UE 5.8 正式版 MegaLights。要点含：成本大致不随灯数线性上涨；街景作例 Directional+Sky 约 13.12ms，加 160 个 RectLight 并切 RT 约 35.59ms，开 MegaLights 后约 16.16ms（演讲自测数字）。更大收益是全部灯可作正确 RT 区域光；建议不必只当局部省钱开关，可常开并大量放 RectLight，再与 VolumetricFog 组合。文亦区分物理必然光与演出光，并称 GI/Lumen 时代仍需照明美术。技术细节指向 Epic Japan 另两场幻灯（可扩展性 / MegaLights 入门）。

为什么有用

比「开 MegaLights」更落地：用演讲数字与「常开 + 大量 RectLight」工作流，重新评估灯数预算与美术职责。

值得试

UE 5.8 工程打开 MegaLights，用场景预算对照文中「160 RectLight」量级做一次 before/after GPU 计时。

Unity 6000.3.28f1：Licensing Client 加速、iPhone 18 枚举、DX12 大场景 mid-frame flush

Unity Release Notes发布:2026-11-03
游戏开发工具

Unity 官方 changelog：6000.3.28f1 于 2026-11-03 发布。Improvements：Licensing Client 升至 v1.19.0（称启动更快）。API：iOS 增加 iPhone 18 Pro / Pro Max / Duo 的 device generation 枚举与刘海/挖孔 cutout。Fixes 中与图形相关：DX12 在单帧大纹理（如动态字体图集）多次更新时的崩溃；IUnityGraphicsD3D12::GetNextFrameFenceValue 在开启 graphics jobs 时可能早于插件写入命令完成的问题；极端单帧绘制量导致 OOM/GPU reset 时，D3D12 在上传 scratch 超过约 1 GiB 会 mid-frame submit，可用 boot config d3d12-scratch-flush-threshold 调整（0 关闭）。另列多项已知问题（Android predictive back、USB 音频断连崩溃等）。

为什么有用

跟 6000.3 LTS/补丁线的团队可直接对照 DX12 scratch flush 与 iPhone 18 设备枚举是否覆盖当前崩溃/适配清单。

值得试

升级到 6000.3.28f1；若 DX12 大场景仍爆显存，试调 d3d12-scratch-flush-threshold 并看日志首次 flush 提示。
