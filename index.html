AI coding agents generate more code, but not more software

报道哈佛研究者 Fiona Chen 与 James Stratton 的研究:用 Jellyfish 的工程数据(700 多家公司、70 万以上员工、2021 年至 2026 年 3 月)做双重差分分析。引入 AI 编码 Agent 后,代码行数平均增加约 30%、提交数增加约 20%、PR 数增加约 23%,但 Jira 里 Issue/Epic 的完成率没有统计显著变化;PR 从提交到合并的评审时间平均拉长 49%,需要修改的 PR 比例接近翻倍,每个 PR 的评论数增加 35%。研究数据截止 2026 年 3 月,文章也提到之后 Agent 已有不少更新;这是对研究的报道,我们没有读论文原文。

CLI: make daemon_auto_start opt-in(Codex CLI 默认常驻后台守护进程)

这是一位用户提交、仍处于 open 状态的 Issue,10 月 12 日在 Hacker News 上引发热议。报告称自 Codex CLI 0.157.0 起,打开交互会话就会启动一个常驻的后台守护进程(关掉窗口也不退出),把约 374 MB 的平台包复制到 ~/.codex/packages/app-server-daemon/,并启动每小时检查更新、可自行重启后端的更新进程;守护进程还会沿用第一个启动它的会话的环境变量(如代理、GH_TOKEN 等)。评论里有人在 Windows 上确认,也有人报告旧版本堆积到 2.8 GB。这些是用户报告,OpenAI 官方尚未在该 Issue 中回应,我们也没有自己复现。

SteadySplats: Resampling of Low-Variance Gaussians for High-Fidelity Stochastic Rendering

论文针对 3D 高斯泼溅的随机顺序无关透明(Stochastic OIT)渲染噪点大的问题,提出三部分:训练时加颜色方差正则,让落在同一像素的高斯颜色趋同;推理时基于历史样本的空间重采样(类似 ReSTIR 思路,用最近 K 个样本近似遮挡);以及可写成指数滑动平均的时序重采样加软历史拒绝,配合时空蓝噪声。作者报告在 Mip-NeRF 360 上 1 spp 时比以往随机方法 PSNR 高约 13 dB,在 RTX 5090 上的 Vulkan 实现中 K<14 时帧率高于排序的确定性 alpha 混合。代价是收敛后峰值画质略降、空间重用不再严格无偏。以上均为论文自报结果。
