How SEED renders a world players never stop building

Unity Blog发布:2026-11-06
游戏开发效率

Klang Games 用 Unity URP 做持久沙盒 MMO《SEED》：客户端只渲染服务器流式状态。建筑拆成约 1m 网格模块，用 BatchRendererGroup + Job/Burst 合批；表面颜色等多写在顶点而非贴图。PC 上用真实玩家存档剖析后发现偏 CPU：大量带 LOD Group 的 Prefab 因动画 cross-fade 没进 GPU Resident Drawer，仍走 SRP Batcher；关掉动画后恢复 hybrid/instanced 合批。移动端主要卡内存，靠 Memory Profiler 差分、按平台 Addressables，以及把经典 LOD 换成 Unity 6.2 Mesh LOD（多级细节收进同一 mesh）。

为什么有用

玩家共建大世界时，如何用 Profiler/Frame Debugger 抓「该走 GPU Resident Drawer 却没走」这类根因，以及移动端用 Mesh LOD 控内存，都很可直接套。

值得试

在相似 URP 项目里对密集小物件 Prefab：Frame Debugger 看是否 hybrid batch；有 LOD cross-fade 动画时对照关掉动画后的合批与 CPU 提交时间。

Speed Up Image Generation with FLUX 3 Image Klein on NVIDIA Blackwell GPUs

NVIDIA Developer Blog发布:2026-11-06
图形渲染前沿

Black Forest Labs 的 FLUX 3 Image Klein（Base / distilled）用 Qwen3-VL-4B 做文本条件、DiT 细化 latent、自编码器编解码；NVIDIA 文介绍如何在 TensorRT LLM VisualGen 上配 NVFP4、融合 GEMM、torch.compile、FP8 注意力、Cache-DiT 步进缓存与多卡并行。文中给出单卡 B200 上相对未编译 BF16 的加速数字（例如组合优化后文生图最高约 3.46×、图生图约 4.45×），以及八卡 B200 上的延迟对比——均为厂商博客测量，需按自有 workload 复现。

为什么有用

若在 Blackwell 上部署扩散图生/图编，可对照 VisualGen 的量化、缓存与并行开关逐项压延迟。

值得试

按文中 YAML 跑官方 FLUX 3 VisualGen 示例，先比 BF16 vs NVFP4 的 T2I 延迟，再决定是否开 Cache-DiT / 多卡。

Claude Code 2.1.319：MCP task 默认后台跑 + denyInsteadOfPrompting

GitHub anthropics/claude-code发布:2026-11-06
AI 工具工具

终端里当 MCP 把某次 tool call 作为 task 跑时，Claude Code 会立刻放到后台，结束后再把结果告诉模型；可用 CLAUDE_CODE_DISABLE_MCP_TASK_BACKGROUND 恢复阻塞等待，CLAUDE_CODE_DISABLE_MCP_TASKS=1 关掉 MCP tasks。新增 permissions.denyInsteadOfPrompting：本会卡在权限提示的调用直接拒绝并继续回合。另有 /claude-api latency-optimize、CLAUDE_CODE_DISABLE_FEATURE_FLAGS，以及关 telemetry/feature-flag 时 auto mode 不再回落到内置分类器等行为变更（详见 release notes）。

为什么有用

慢 MCP 不再堵整段会话；若你的集成依赖「等 task 结束再继续」的旧顺序，需要显式设环境变量。

值得试

升级到 2.1.319 后对慢 MCP 试一次；若顺序乱了：export CLAUDE_CODE_DISABLE_MCP_TASK_BACKGROUND=1。
