DirectX Dump Files 零售可用：Agility SDK 1.620 + PIX 2610.28 统一 GPU 崩溃转储

DirectX Developer Blog发布:2026-10-28
图形渲染工具

微软宣布 DirectX Dump Files 可进入零售游戏：搭配 Agility SDK 1.620 与 PIX 2610.28，可在玩家机与开发机捕获 GPU 崩溃（.dxdmp），再在任意 PC 用 PIX 分析，无需复现原 GPU。默认 NO_OVERHEAD 驱动选项、无需 Developer Mode；预览期的 .dxdmp_preview 扩展名改为正式 .dxdmp。文中列出三档场景（开发/QA 保留转储、日常零售、对少数玩家临时开 MEDIUM/HIGH_OVERHEAD）及硬件表：AMD RX 7000/9000（MEDIUM/HIGH）、NVIDIA Turing+ 且 R620+（含 NO_OVERHEAD）、Intel/Qualcomm 仍标 Coming soon。已知限制含软件设备移除（非 TDR）暂不生成 dump；厂商插件数据深度不一。

为什么有用

跟 PC GPU 偶发 TDR/挂起的团队，这是零售路径下统一拿到可 PIX 分析的跨 IHV 转储的入口清单。

值得试

升到 Agility SDK ≥1.620 与 PIX ≥2610.28；开发机用 RetainDumpFile / D3DConfig 留本地；零售走 dump end callback 上传，需要时再对少数会话 ConfigureDumpFile 提 overhead。

游戏开发工具

官方 release notes 在 2026-10-29 记入 1.0.0-beta.15（上一档 beta.14 为 10-21）。要点包括：unity docs cache add 可把手册（及可选 --api）下成 Markdown 供离线查；项目可用 ProjectSettings/UnityCliConfig.json 的 cli.version（npm 风格范围）钉住 CLI，CI 超出范围直接失败；unity projects create --install-editor 可在缺 Editor 时先安装再创建，3D 新建项目默认加 Cinemachine（--bare 可跳过）；unity install --set-default、pipeline upgrade 跟最新已发布 Pipeline 包、插件经 UNITY_CLI_CTX_* / UNITY_CLI_CTX_JSON 拿到项目与运行上下文等。安装脚本改为装最新稳定版，beta 需 UNITY_CLI_CHANNEL=beta。本机未安装验证；页面同时含更早版本说明。

NVIDIA Recovery：开源集群级训练作业自动恢复（Slurm，默认先 monitor）

NVIDIA Technical Blog发布:2026-11-02
AI 工具工具

NVIDIA 介绍开源服务 NVIDIA Recovery（属 DSX OS）：在集群层对训练作业做检测→归因→隔离→按策略重启/停止，信号来自应用日志、GPU 指标与调度器；与 NVSentinel/NVRx 等分层互补。当前支持 Slurm（含 Slurm-on-Kubernetes），Kubernetes 原生在路线图。新部署默认 monitor/observe：只给建议、不改调度，确认信噪后再开自动动作；提供 Helm、审计轨迹与 Recovery Console。文中称某训练集群 7/9–10/9 监测约每日近 200 作业、约 8550 次异常检测，平均检测/恢复动作延迟约 69/94 秒（厂商自报，未复现）。仓库 Apache 2.0；页首有 AI 生成摘要提示需核对正文。

为什么有用

跑多机多卡训练、半夜手动捞 NCCL/挂起的人，可先用 monitor 模式对照自家运维决策再决定是否托管重启。

值得试

按文内链到 dsx-ai-factory/NVIDIA-Recovery；Helm 快速入门可无物理 GPU；sbatch 用 comment 里 nvidia-recovery 字段 opt-in，先 mode=observe。
