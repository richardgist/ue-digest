AMD GPUOpen：Agility SDK 1.620 / 1.722-preview 的 Radeon 日一支持（含 DXR Clustered Geometry）

AMD GPUOpen发布:2026-11-03
图形渲染工具

AMD 原文标注 2026-11-03：配合微软 10/28 发布的 Agility SDK 1.620（零售）与 1.722-preview，同日提供两套驱动——Retail Edition 26.20.12.02 与 Developer Preview Edition 26.20.12.01。文中列出零售特性（DirectX Dump Files、Extended PIX Markers、Partial Graphics Programs 等）在 RX 7000/9000 与 AI PRO R9700/R9600 的支持表；1.722-preview 的 Clustered Geometry / Partitioned TLAS / 间接加速结构构建目前标在 RX 9000 与上述 AI PRO 系列。文中转载微软在 RX 9070 上跑 D3D12RaytracingClusteredGeometry 样例的对比数字（传统 BLAS 重建 vs Clustered Geometry），并注明为单配置测试、游戏不应假设同等提升。另述 ASD（含 UE 5.8.4 SODB）、RRA 1.11.1、PIX 2610.28 与 DxCGC 独立预览驱动等入口。

为什么有用

跟 DX12/DXR 或刚升 Agility SDK 的人，可按 AMD 对照表选 Retail/Preview 驱动并核对 Clustered Geometry 样例与 GPU 范围。

值得试

零售特性用 Agility SDK Retail Edition 26.20.12.02；试 DXR preview 用 Developer Preview 26.20.12.01 + Agility 1.722-preview + SM 6.10 preview DXC，并开 Developer Mode 实验特性；样例见微软 D3D12RaytracingClusteredGeometry。

NVIDIA Attribution 开源：把分布式训练失败归因到根因节点与证据链

NVIDIA Technical Blog发布:2026-11-02
AI 工具效率

NVIDIA 介绍开源的 NVIDIA Attribution：面向单次 workload attempt，把日志、指标、遥测与调度器状态关联成结构化诊断（outcome、root cause、受影响节点、supporting symptoms、evidence trail）。组件为 Attribution Service（HTTP API）与 Attribution Blueprint（连接 Slurm/Kueue/静态输入与 Loki/本地文件/K8s pod 日志/PromQL 等）。文中用合成样例说明如何把 node-02 上的 XID 149（NVLink signal integrity）定为根因，并把各 rank 的 NCCL 错误保留为症状。页首有 AI 生成摘要提示；文中称生产环境每周分析数百万作业（厂商自报）。仓库含 Docker quickstart 与规则目录；可与前一日介绍的 Recovery 互补（归因 vs 自动恢复）。

StateBench：长上下文「状态追踪」四级基准（Allen AI / Hugging Face）

Hugging Face Blog · Allen AI发布:2026-11-03
AI 工具前沿

Allen AI 在 HF Blog 发布 StateBench（2026-11-03）：按变量赋值难度分四级（R-trivial 不可变赋值、Aperiodic 按值重赋、Soluble 自引用更新、General finite 按引用赋值/交换），用来测模型在长文档中跟踪实体状态的能力。预训练开源模型在 r-trivial 较好、aperiodic 随长度掉点、general finite 接近随机；直接在任务上训练时，Gated DeltaNet/hybrid 在前三级可泛化到远超训练长度，transformer 仍学不会最难级。文中称 Gemini 3.8 Flash、Claude Opus 5.5、GPT-6 Sol/Luna 等前沿模型在 soluble/general finite 上随输入变长准确率骤降（最长 general finite 可到 13% 或更低，原文数字）。动机含对照 recurrent/hybrid 与理论极限；文末列出仍开放的问题。

为什么有用

做长上下文、代码变量追踪或选型 recurrent/hybrid 架构时，可用四级难度对照「卡在读最新值还是跟链式更新」。

值得试

读文内四级定义与图示；若评自家模型，按同序列派生四级变体，先看 aperiodic→soluble 掉点位置。
