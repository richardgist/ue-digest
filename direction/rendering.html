VisibilitySplat: Ray-Traced Occlusion for Relighting with 3D Gaussian Splatting

Rostock 大学论文提出 VisibilitySplat：在保留标准 3DGS 光栅化训练/预览的前提下，用 BVH 加速的点基光线追踪作为稀疏可见性预言机，估计采样光照方向上的透射加权遮挡，配合 Disney 系微面元 BRDF 与低分辨率 HDR 环境贴图做材质与光照分解、重光照。在 TensoIR 合成集上与 NeRFactor、GS-IR、TensoIR、IRGS 等对比，重光照等指标有竞争力；作者自跑 IRGS 评价后称 IRGS 总体仍领先。消融显示显式可见性主要改善重光照与材质-光照解耦；纯 PBR 监督反而可能抬高新视角外观分数却损害分解。局限：仅掩膜单物体合成场景、直接光、非实时（A6000 上约 0.83 s/图重光照）。代码声明待正式发表后开源。

论坛：Lumen HWRT 因持久化 SBT 引用已释放 Index Buffer 导致 GPU Page Fault

在开启 Lumen Hardware Ray Tracing、关闭 Generate Mesh Distance Fields 的大型 World Partition 场景中，静态网格被替换/流送释放后，HWRT 着色器仍通过 Persistent SBT / RayTracingSceneMetadata 读已释放的 index buffer，触发 DXGI DEVICE_HUNG / Page Fault（编辑器、PIE、Shipping 均可复现）。报告者称 r.RayTracing.PersistentSBT=0 可暂时避开崩溃，但会显著抬高 Render Thread 成本与延迟。

SteadySplats: Resampling of Low-Variance Gaussians for High-Fidelity Stochastic Rendering

论文针对 3D 高斯泼溅的随机顺序无关透明(Stochastic OIT)渲染噪点大的问题,提出三部分:训练时加颜色方差正则,让落在同一像素的高斯颜色趋同;推理时基于历史样本的空间重采样(类似 ReSTIR 思路,用最近 K 个样本近似遮挡);以及可写成指数滑动平均的时序重采样加软历史拒绝,配合时空蓝噪声。作者报告在 Mip-NeRF 360 上 1 spp 时比以往随机方法 PSNR 高约 13 dB,在 RTX 5090 上的 Vulkan 实现中 K<14 时帧率高于排序的确定性 alpha 混合。代价是收敛后峰值画质略降、空间重用不再严格无偏。以上均为论文自报结果。

[UE 5.8.3][Lumen] Broad interior light leakage in a sealed stock-cube room with Screen Probe Gather

用户在全新空白项目里用 6 块引擎自带 Cube 拼成完全封闭的 20×20×5 米房间,只放一盏室外平行光,Lumen 默认的 Screen Probe Gather 下室内墙面出现大面积“漏光”发亮;同机位同曝光的 Path Tracing 是全黑,把 r.Lumen.FinalGatherMethod 从 1 改成 0(Irradiance Field Gather)后发亮消失、改回 1 又出现。帖子给出了完整的板块坐标、光源参数和基线 CVar,可完整复现;2×2×2 米的小房间则基本不漏光。
