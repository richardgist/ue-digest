UE 5.8.4 热修：VS 2026 .slnx、Lumen SceneCapture 回归与 ASD SODB 工具

Epic 于 2026-10-20 发布 UE 5.8.4 热修。编辑器侧：修复每次打开源文件都新开 Visual Studio 2026 实例的问题，并识别 .slnx；若同时存在 .slnx 与 .sln 则优先 .slnx。渲染侧：修复 SceneCapture2D 渲染材质时每帧误清空 Lumen 间接光 atlas 的回归；Path Tracer 在部分 Substrate 材质上补回 specular profile；改进 D3D12 enhanced barriers。ASD：支持用 ASDTool 从已 cook 游戏为 compute shader 与捆绑 PSO 生成 SODB。另有 Movie Render Pipeline、MetaHuman、Horde 路径遍历等多项崩溃/安全修复。已知问题 UE-401568：PCG Editor Mode 画笔工具不实时更新，做任意其他操作后网格才会出现。论坛跟帖中有用户报告 HDR 崩溃、升级后多占约 3GB RAM 等，官方帖未宣称已解决。

    PerfGuard：Nanite 性能深潜——簇剔除、软/硬光栅与 Masked/WPO 成本

图形渲染UE 日报06

官方文档：移动端 Mesh Auto-Instancing（GPU Scene，含 Mali 纹理路径）

移动端可开启网格自动实例化以合并 Draw Call：在 DefaultEngine.ini 设 r.Mobile.SupportGPUScene=1，并用 r.Mobile.UseGPUSceneTexture=1 把 GPU Scene 数据存进纹理而非 buffer，从而让仅支持约 64KB buffer 的 Mali 也能用。开启会触发移动端着色器重编。文档强调主要利好偏 CPU 瓶颈的项目；GPU 瓶颈收益可能不明显；若极吃内存可关 UseGPUSceneTexture 改回 buffer（但 Mali 会失去该特性）。要求结合真机 profiling 判断是否值得上线，并提醒除通用 Mesh Drawing 限制外还有移动端特有约束。

Anchor3DGS：用熵引导的 3D Anchor 做前馈高斯溅射，高斯数量约少一个数量级

清华与蚂蚁集团论文（Submitted on 15 Oct 2026）。提出 pose-free 前馈 3DGS：用 VGGT 几何骨干建 scaffold，按信息熵在 3D 放置固定预算的 anchor（文中默认 N=32768，每 anchor 解码 K=8，约 0.26M 高斯，与输入分辨率/视角数解耦），经遮挡感知多视角聚合与跨 anchor 注意力后解码局部高斯，再用轻量 UNet 增强高频。稀疏视角（3/6 视图）在 VR-NeRF、MipNeRF360、DL3DV 上相对 AnySplat 等基线报告更高 PSNR/SSIM/更低 LPIPS；稠密 32 视图质量可比且存储约 35MB。作者自报 SOTA，基线与协议以文内表格为准，未独立复现。局限：依赖几何骨干位姿/深度质量；固定 anchor 预算对超大场景可能不够。

按目标机把移动光照能力分成可用档位：LDR（关 Mobile HDR）追求最低开销，场景色在 gamma、半透明需按 gamma 空间重做，无后期，材质宜 Unlit 并尽量把计算放进 Vertex/Customized UV；基础光照档开 Mobile HDR，用静态光照与 Fully Rough 材质换取更广设备覆盖，可关 Lightmap Directionality 进一步省性能，并限制部分后期。文档要求按目标机列表选档，而不是默认堆桌面级动态光。

微软宣布 Advanced Shader Delivery（ASD）已在 Windows 11 24H2+ 上面向 AMD、Intel、Nvidia、Qualcomm 设备广泛可用：在游戏下载时下发预编译着色器，目标是缩短首次加载、减轻运行时 shader 编译卡顿并降低功耗。文中给出各厂商驱动门槛（如 Nvidia 621.01+、AMD Adrenalin 26.6.1+ 等），并以 Call of Duty: Modern Warfare 4 为例称开启 ASD 后首次着色器编译可从数分钟降到数秒（厂商自述，本文未独立复测）。开发者侧：文档说明如何收集并上传 State Object Database（SODB）；UE 5.8.4 已可把 SODB 编进流程，Unity 的 SODB 集成写明要到 2027。另称即将扩展到 Epic Games Store 与 Steam，Fortnite 也会跟进（时间表未写死）。

实测：UE5.8 行星场景 VRAM 从 12.5GB 压到 5.3GB，云层 15.5→3.5ms

作者在 3440×1440 / RTX 5070 Ti 上给出可复现测量：进程 VRAM 从 12,480MB 降到 5,256MB（未降纹理画质），地形 chunk 从 2,055→752、三角形 69.4M→25.4M。主要手段包括动态网格改为索引几何、修正低空地平线剔除、把 8K 天空立方体贴图压到可视分辨率、以及为 TSR/Nanite/体积雾/GI atlas/反射捕获池设预算。体积云从约 15.5ms 降到 3.5ms（更小天气图、时间重投影、减少云阴影射线采样）；草地场景 GPU 中位约 22.9→11–12ms，实例遮挡剔除单独贡献约 −5.16ms。文中强调成对 A/B、先读内存 dump 再猜，并提醒尚未在 8GB 卡上诚实测过。
