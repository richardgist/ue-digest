Splatting the Gaussians into Blender

Blender Developers Blog发布:2026-10-30
图形渲染前沿

Blender 5.3 引入原生 3D Gaussian Splat：可导入 .PLY / .SPZ，也可从 USD 加载；在编辑器里以点云形态表示，Geometry Nodes 提供 Pointcloud Type，属性含 Position、三维 Scaling、四元数 Rotation，以及拆成 radiance:base / radiance:sh 的球谐辐射。Workbench / EEVEE 用光栅化投影为 2D billboard（EEVEE 初版走 dithered 透明，噪声需提高采样；Workbench 需 Flat 光照预览）；Cycles 对每条射线求与 splat 的最大不透明度交点并用随机接受做不透明，以兼容二次射线与 GI，并注明与 EEVEE 在透视/训练假设上会有细微差异。文中给出重光照、法线估计的早期做法与当前限制（EEVEE overdraw、编辑工具仍偏点云、重光照仍早期），并列出后续性能与工具改进计划。

为什么有用

若你在 UE/自研管线外需要把 3DGS 捕获直接进 DCC 做剪辑、节点处理或对照 Cycles/EEVEE 表现，这是官方一手说明与限制清单。

值得试

升到 Blender 5.3，把 .PLY/.SPZ 拖进视口导入；EEVEE 适当提高 Viewport/Render 采样，Workbench 切 Flat；需要重光照时在着色器改 emissive/radiance 并对照 Cycles 结果。

How to Check and Configure NVIDIA GPUDirect Storage for Your Platform

NVIDIA Technical Blog发布:2026-10-30
AI 工具效率

NVIDIA 发布开源 CLI `gds-diag`（GPUDirect Storage 团队出品，随 Magnum IO 仓库分发），用于评估 GDS 环境、定位问题并给出改进建议。子命令覆盖端到端检查、安装前验证、安装后确认，以及对容器与具体挂载点的深挖；结果带 FAIL/WARN/INFO/PASS 等状态、说明与缓解建议。另附可选 agent skill：用自然语言编排多步诊断并做模型辅助解读（仍落在同一 CLI 上）。运行要求：Linux + Python 3.8+；完整 GDS 功能需要数据中心级 GPU 与 CUDA 12.2+，但文中写明这些不是 gds-diag 自身依赖。安装：`git clone https://github.com/NVIDIA/MagnumIO.git`，进入 gds-diag 目录。页首亦有 AI 生成摘要条。

为什么有用

训练/推理 IO 瓶颈时，比翻长篇 GDS 文档更快做基线体检；也可让 Claude/Codex 直接打开该目录用 skill 做自然语言分诊。

值得试

克隆 MagnumIO，`cd` 到 gds-diag 后跑 `python3 gds-diag.py --help` 并按文档做端到端检查；需要自然语言编排时用 coding assistant 打开该目录启用 agent skill。
