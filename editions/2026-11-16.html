论坛：UE 5.8 Vulkan 硬件光线追踪下 bindless 描述符延迟写入导致 GPU hang（含补丁）

LifeBandit7575 报告：UE 5.8 的 Vulkan RHI 在默认开启的 bindless（VK_EXT_descriptor_buffer）下，FVulkanShaderResourceView / FVulkanUnorderedAccessView 会在构造函数里分配 bindless 槽位，但描述符要等 RHI 线程的 EnqueueLambda 才写入；若命令列表先提交，GPU 会读到该槽位的前一个所有者（硬件光线追踪时常见为加速结构或 3D 纹理），顶点着色器取用后就会 GPU hang。发帖人在 Linux、Intel Arc A750、Mesa ANV 26.2.6 / 26.3.0 上，用约 300 个每帧重建顶点缓冲 SRV 的 UMaterialBillboardComponent（半透明加法材质），在 -game 中打开 r.RayTracing.Enable 1 并配合 r.RayTracing.Shadows 1 或 r.Lumen.HardwareRayTracing 1 后复现：启用 RT 后约 6–74 秒出现 hang（中位数约 13 秒），一晚超过 40 次。补丁是在构造函数里也对 buffer view（不含加速结构）调用 UpdateView；按发帖人验证，11/11 次通过（8 次 RT 阴影、2 次 Lumen HWRT、1 次关闭 RT）且未见回归。该帖尚未提供空白工程复现，也还没有 Epic 官方确认。

CORTAO：开源的基于圆形遮挡体与屏幕空间光线追踪的实时 SSAO，可作为引擎原有 SSAO 阶段的替换

Fenris Creations（EVE Online / EVE Frontier）于 2026-11-12 宣布开源 Circular Occluder Ray-Traced Ambient Occlusion（CORTAO），作者是高级渲染工程师 Daniel Isheden。参考实现仓库 theagentd/CORTAO 的 README 版本记录写 1.0.0 初始发布为 2026-11-05，随后在 11-13 到 11-15 发布了 1.0.1–1.0.3 的修复；仓库采用 MIT 许可证。技术说明把 CORTAO 定义为基于屏幕空间光线追踪的物理实时 SSAO：从深度缓冲采样，把像素邻域近似成圆形遮挡体，再对这套代理几何求交，并用预计算查找表追踪每像素最多 32 条光线，同时可计算 bent normals。作者用它对照 GTAO（Jimenez 等，2016），认为水平线方法在倾斜、不正对相机的表面上会偏斜，难以收敛到暴力光线追踪参考；这些准确性、稳定性以及“以更少样本达到更高质量”的说法来自仓库 README 和公司稿，本机未复现。仓库给出的作者测试结论包括：简单场景中，CORTAO 用不到一半的 GPU 时间达到与 GTAO 相当的精度，或在相同 GPU 时间预算下平均平方误差最多低约 4 倍；复杂场景中，在更低样本数下平均平方误差明显更低，并在提高样本数后收敛到比 GTAO 更低的误差。仓库还写：着色器提供 HLSL 与 GLSL；已测试可在 DirectX 11（需 Shader Model 6.7 的变通）、DirectX 12、OpenGL 4.3+ 和 Vulkan 1.0+ 上直接使用；HLSL 完整路径的最低要求是 Shader Model 6.7。实现分 prepass、main pass 和可选的空间滤波 pass，用于给后续时间滤波做准备；仓库目前不自带时间滤波，需要引擎侧另行接入。面向 Carbon 引擎、针对大深度范围太空场景的精简实现另在 carbonengine/CORTAO。公司稿称该技术已在开发中的 EVE Frontier 中测试，并设计为替换引擎现有的屏幕空间环境光遮蔽阶段。本机未编译或跑分。

FastWild-GS：用紧凑的逐图外观适配，在数分钟内做野外照片集的 3D Gaussian Splatting

Chung-Ang University 的 Donghun Ryu、Seokhyun Kim 与 Minhyeok Lee 的论文 FastWild-GS 于 2026-11-10 提交到 arXiv（2611.13808v1）。论文针对互联网照片集中曝光、光照和过路人等瞬态物体不一致的 in-the-wild 设定：同一套高斯颜色无法解释所有照片，而近期同类方法多报告每场景数小时优化。FastWild-GS 用 128 维 Photo Appearance Token（PAT）描述每张照片，再加上作用在渲染图上的每通道 scale 与 offset（共 6 个参数）；一个小 MLP（PAT Decoder）根据该 token 和每个高斯的特征预测颜色，用来替换球谐颜色。稠密化与剪枝打分用的渲染图也会套上同一套逐图变换，避免把曝光或色彩差异当成重建误差。对留出照片，场景固定，只在图像左半边拟合该照片的外观参数，右半边用于评测。作者报告的结果（文中写在一块 RTX 5090 上测量，本机未复现）：在 PhotoTourism 上每场景训练 8.8 分钟，在所比较方法中 LPIPS 最低，比 LPIPS 次优的 AsymGS 快 23 倍；在 NeRF-OSR 上每场景 9.7 分钟，平均 PSNR、SSIM 和 LPIPS 在所比较方法中最好。摘要还写加速版 3DGS 训练虽能到分钟级，但通常假设采集外观一致。本机未训练或核对表格中的具体指标。
