NVIDIA RTX Spark：游戏侧神经渲染、DLSS 5、Nsight WoA 与 NvRTX 5.8

NVIDIA 技术博客介绍 RTX Spark（Blackwell RTX GPU + Grace CPU、最高约 128GB 统一内存）上的游戏开发相关栈：DLSS 套件（含 Super Resolution、Ray Reconstruction、Dynamic Multi Frame Generation、3D-Guided Neural Rendering）；称 10 月 DLSS 5 模型相对 9 月版“快约 2 倍、GPU 开销约减半、4K VRAM 约降 20%”（厂商自述，未独立验证）；DLSS 4.5 UE 插件 8.9.0 为 UE 5.8 增加官方 Windows on Arm 支持；Nsight Graphics 2026.3 提供 WoA 安装包，Nsight Systems 2026.5 起 Windows 统一安装包覆盖 native Arm64；并提到 NvRTX 5.8（侧重重构/稳定/兼容）与 RTX Kit 八项技术在 Spark 上的支持列表。另含 ACE/Nemotron 3.5 Bolt 本地 NPC 等内容，属厂商推广口径。

    GeoGSplat：带几何先验的非像素对齐前馈 Gaussian Splatting

    arXiv 2610.36760（2026-10-27）：前馈 3DGS 若按像素对齐预测，高斯数量会随分辨率与视角数膨胀；非像素对齐方法用固定数量高斯，但缺少显式射线/深度约束时中心易错位、大视角变化下易出伪影。GeoGSplat 在非像素对齐框架中引入几何先验：双分支编码器构建 Anchors 与 Triplane，分层解码器逐步解码稠密 3D 点与高斯原语。摘要称据此改善大视角变化下的重建与渲染稳定性。论文方法与指标以原文为准，本地未复现实验。

TensorRT Global Performance Tuner Part 2：构建路线搜索与实践

接 Part 1（已收录）：本篇讲 TensorRT 11.1 Global Performance Tuner 的实现与用法——把调度策略表示为可搜索的 build route（编译器旋钮组合）；C++ API 可 set/get 当前 route，并枚举 200+ 旋钮空间；`trtexec` 展开 route 表达式、逐条构建/测速/测精度，丢弃崩溃或精度不合格者，再选最快合格引擎。文称在 10 个评估工作负载上相对默认 route 约 1.14×–1.63×（厂商评测）。实践建议：按搜索空间选 fast/mixed/full、`--dryRun` 预览、`--tuningCacheFile`+`--continue` 断点续跑，换模型/形状/GPU/软件栈后需重调。Python 侧称将随 Torch-TensorRT 2.15 提供同类实现。
