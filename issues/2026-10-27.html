Last Week in Unreal（10/19–10/25）：5.8.4 落地；移动端环境光体积半分辨率与 Distortion 默认变更

SpeedrunCI发布:2026-10-26适用版本:ue6-main（文中对照 5.8.4；移动端 CVar 变更在 ue6-main）
图形渲染移动端渲染

周报称 5.8.4 已于 10/20 打 tag（内容止于约 10/5 的热修候选，上周建议的 ue5-main 修复未进包）。ue6-main 本周默认值变动里与移动/渲染相关的包括：移动延迟渲染器上环境光体积 tint 烘焙默认半分辨率（r.AmbientLightingVolume.MobileBakedTintsDownsample=2，设 1 可回全分辨率）；移除 r.Mobile.Distortion.BeforeTranslucency，且「Distortion is disabled with mobile MSAA」。另述光追 closest-hit payload 从 64 压到 32 字节（可能出现法线条带）、Device Profile CVar apply mode 2 成默认、着色器库默认释放无引用着色器等。文末列出建议在 5.8.4 上额外 cherry-pick 的物理手柄 UAF、Niagara redo、CEF 等修复（非渲染主线）。

值得试的点

  • 跟 ue6-main / 新引擎的移动项目：对照环境光体积是否偏糊，需要时把 MobileBakedTintsDownsample 设回 1 做 A/B
  • 开了移动 MSAA 又依赖 Distortion 的效果：确认失真是否被关掉，必要时改抗锯齿策略或换实现
  • 仍停在 5.8 出货：升 5.8.4 后按文中「For teams shipping on 5.8」节评估额外 cherry-pick，不要假设已含上周全部 ue5-main 修复

Simplygon：按 ViewPosition 做距离桶代理（近聚合、远减面、可见性剔除）

Simplygon Blog（Jesper Tingvall）发布:2026-10-19适用版本:UE 5.7.4 + Simplygon 10.4.446.0（文内声明后续 API 可能变）
图形渲染HLOD渲染

面向机位受限（如 VR）的关卡：为每个 ViewPosition 按距离桶生成专用几何——最近桶聚合，更远桶按最大偏差减面；近桶结果作为远桶遮挡体，配合九个采样相机（视点+小盒八角）做保守可见性剔除。给出完整编辑器 Python 脚本、异步导出/工作线程跑 Simplygon、导入后打 SimplygonView 标签防重复喂入等流程；空结果可能是整桶被剔光而非失败。

值得试的点

  • 只在机位活动范围很小的关卡试用；先放 ViewPosition，调 BUCKET_SETTINGS 距离与 max_deviation
  • 跑 optimize_views() 后看 Output Log 的 View Bucket Report，核对意外进桶的网格
  • 验收时在九个采样位之间移动对比轮廓与开口，不要只盯中心机位

PerfGuard：GPU 回归系统排查——Draw Call、Overdraw、Lumen、VSM、Nanite

PerfGuard发布:原文未标注（站内教程锚定 UE 5.5/5.6 测量与命令）适用版本:原文未标注（原理适用于现行 UE5 延迟路径；可在 5.8 验证）
图形渲染渲染HLOD

先用 CoV/热节流/卡顿归因确认回归真实，再交叉 DrawCalls 与 TrianglesDrawn：三角升、Draw 平≈Nanite 簇变多；Draw 升、三角平≈非 Nanite/材质拆批。分节覆盖 Draw Call（含内容改动后需重建 HLOD）、半透明 overdraw、Lumen Surface Cache/探针、VSM 页失效与页池耗尽、Nanite 软光栅与 fallback、PSO 首遇卡顿、贴图流送池与显存压力，并给出 stat / viewmode / CVar 清单与「先对通道再上 RenderDoc/Insights」的顺序。

值得试的点

  • GPU 变慢时先看 DrawCalls 与 TrianglesDrawn 是否同向，再用 stat GPU 钉到 BasePass/Shadow/Lumen/Translucency
  • Draw Call 突然升高且最近改过远景：检查是否需要重建 HLOD，并核对 ISM/HISM 与材质槽数
  • Lumen/VSM 嫌疑场景：分别用反射/GI 开关与 Cached Pages 视图做隔离，再改 CVar 写入 Scalability

UE 5.8 World Partition HLOD：层类型选择、5.8 局部构建与验收清单

Game Development Constitution发布:原文未标注（面向 UE 5.8）适用版本:UE 5.8
图形渲染HLOD
