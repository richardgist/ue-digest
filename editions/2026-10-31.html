Epic Office Hours：UE 5.8 MegaLights 入门（生产就绪、设置与调优）

Epic 教育团队 Office Hours 录播，讲解 5.8 起生产就绪的 MegaLights：用重要性采样统一处理大量可投影动态灯光。需 DX12、Shader Model 6.6，并在项目设置、逐灯 Allow MegaLights、后处理体积三处启用；阴影方法可选 Ray Tracing 或 Virtual Shadow Maps。实操建议收紧 Attenuation Radius、避免灯光嵌进几何、用 IES/形状灯与纹理矩形灯，注意 Nanite fallback 导致的伪影；方向光默认关闭需 r.MegaLights.DirectionalLights；支持 Niagara 粒子灯、体积雾与半透明。调试可用 Light Mixer、光照复杂度、MegaLights 视图与 r.MegaLights.* CVar。

    UE 5.8 Virtual Shadow Maps：诊断 Shadow Depths/Projection 与失效源

    面向 Nanite 与大体量动态光场景的 VSM 排障清单：先把成本拆成 Shadow Depths（深度页更新）与 Shadow Projection（投影采样）。用 Virtual Shadow Map 视图看 Cached Page（绿缓存/红未缓存）、Shadow Casters 找失效源，以及 Nanite Overdraw 与 Virtual Page。常见失效源包括移动灯、增删 caster、WPO/PDO、骨骼变形、过大包围体与镜头切。给出收紧边界、远处关 WPO/投影、Contact/Distance Field 阴影替代、仅在刚性断言成立时用 Invalidation Behavior 覆盖等杠杆；并提醒 r.Shadow.Virtual.Cache 0 只用于诊断。

[PREVIEW] Raytracing: Clustered Geometry, Partitioned TLAS, Indirect Acceleration Structure Builds

微软在 Agility SDK 1.722-preview（同日还有 1.620 零售版）里放出自 2018 年 DXR 亮相以来幅度最大的光追更新：Clustered Geometry（CLAS，单簇最多 256 三角/顶点，可组装 Cluster BLAS 并跨 BLAS 复用）、Partitioned TLAS（按分区稀疏更新，未改分区可保留结构）以及统一的 GPU 驱动加速结构构建 API（GetRTASOperationPrebuildInfo / ExecuteIndirectRTASOperations）。官方说明：不要求超出现有光追的新硬件能力；当前驱动支持含全部 RTX、AMD RX 9000、部分 Intel Arc B / Core Ultra；需 Shader Model 6.10 预览与 Developer Mode。文章强调 Gears of War: E-Day 已通过 NVIDIA 厂商 API（RTX Mega Geometry）采用同类能力，DirectX 标准化意在跨厂商。文中样本对比表（AMD RX 9070 沙盒）显示量级加速，但微软明确写了「不要假设游戏会看到同样量级收益」。另有 PIX 预览与 Microsoft/NVIDIA 样本链接。

UE 5.8 MegaLights 性能清单：固定采样预算、方向光默认关闭与可调 CVar

按 UE 5.8 生产就绪口径整理 MegaLights：每像素固定采样预算，灯再多时帧时相对稳定，但重要灯竞争同一像素时噪声/质量会掉。方向光需显式开 r.MegaLights.DirectionalLights，Epic 更推荐强太阳用 Deferred+VSM；诊断用 light finder / ray visualizer，并对比整帧 GPU 而不只看单个事件。给出 Allow、DownsampleMode、NumSamplesPerPixel、逐灯 Shadow Method 等缩放杠杆。

UE 5.8 Nanite 几何成本：可视化、流送池与 Masked/WPO 杠杆

提醒 Nanite 不消除材质、Masked 叠盖、WPO、阴影、流送与存储成本。诊断用 Nanite Visualization 与 NaniteStats（含 VirtualShadowMaps 视图）；流送池抖动可加大 r.Nanite.Streaming.StreamingPoolSize 或减常驻需求；Masked/WPO 要看 Overdraw 并限制距离。强调不要用三角面数当性能目标，要量 Nanite pass、材质/阴影、流送与 fallback。
