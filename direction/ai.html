    Claude Code 2.1.321：默认 Fable 5.2，以及 MCP OAuth / 沙箱 / cp·mv 权限修复

    anthropics/claude-code 于 2026-11-09 发布 v2.1.321（GitHub 时间 2026-11-09T19:22:30Z）。新增 Claude Fable 5.2（claude-fable-5-2）并列为默认 Fable 模型，发布说明写明 1M 上下文、每百万 token 输入 $8 / 输出 $40、缓存读取 $0.20/Mtok。claude remote-control 增加 --settings，会把指定设置文件应用到它启动的每个会话；文件改动后需重启 remote-control 才会开始新会话。权限与安全相关修复包括：MCP OAuth 在服务器重定向时把 refresh token 等密钥发到另一主机；只读 Bash 命令在沙箱外执行却未弹出权限提示；Bash 权限检查从错误目录判断写文件因而不提示；把文件 cp/mv 进目录时 deny 规则和受保护文件提示未作用到实际写入的那个文件；以路径写出的 /bin/cp、/bin/mv 现在与直接写 cp/mv 走同一套路径检查。行为变化方面：已保存的 Fable 5.1 选择会迁到 fable（Pro/Max 立即生效，Team/Enterprise 需组织允许后生效，可用 /model claude-fable-5-1 切回）；Claude 写出的 mods 在 auto 与 bypass 模式下会直接启用而不再询问（即使有托管的 allowUnsandboxedCommands: false 或 allowManagedDomainsOnly），且在 dontAsk 模式下不加载；mods 自身的 $.tool.call / $.mcp.call 不再弹出权限提示，deny 规则与组织策略仍生效。此外还修复了网络路径上 NotebookEdit/Edit 误改、Windows 启动找程序方式、fast mode 在限流时长时间重试等问题。未在本机升级验证。
