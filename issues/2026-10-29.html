PerfGuard：约 30 个真正能动毫秒的 UE5 CVar（含实测影响）

PerfGuard发布:约 2026-10适用版本:UE 5.5 / 5.6 锚定（文中标注）
图形渲染渲染移动端

整理约 30 个高影响 CVar：Lumen HW/SW 与 Screen Probe、Nanite 光栅/流送池、VSM/SMRT、TSR、PSO 预缓存、MegaLights 降采样等，并给出默认值、分档建议与来自 GPUOpen / Tom Looman / Epic 文档的实测量级。强调数字绑定具体硬件与场景，升级时还要核对 5.5/5.6 默认值变更。

UE 5.8 World Partition：流送源、运行时网格与安全传送清单

Adventures in Causality发布:原文未标注（文档目标 UE 5.8）适用版本:UE 5.8
图形渲染HLOD渲染

讲清流送源模型（Target State / Priority / Shape、以及按需指定 Target Grid 与 Target HLOD Layer）、用「最大接近速度 × 最差就绪延迟 + 前瞻 + 安全余量」估算 Loading Range，并给出安全传送与高速穿越模式。建议默认单层 2D Runtime Spatial Hash，多网格只在 profiling 证明某类内容需要不同 cell/range 时再加。

  • 调参时不要同时改 Cell Size 与 Loading Range；用 wp.Runtime.* 调试命令诊断后，录最终性能前务必恢复作者设置。
