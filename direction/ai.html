llama.cpp v1.0.0：libllama / libggml 进入语义化版本，用不兼容的主版本号标出 API / ABI 变更

Hugging Face 博客于 2026-11-13 宣布 llama.cpp 与底层张量库 ggml 同时发布 v1.0.0：llama.cpp v1.0.0 对应 libllama（公开头文件在 llama.cpp/include/），ggml v1.0.0 对应 libggml（头文件在 ggml/include/）。官方把这次 1.0.0 定位为对下游集成者的承诺：此后 llama.cpp 和 ggml 会在出现 API / ABI 不兼容时提升主版本号。文中给出适用于 ggml-org 采用语义化版本项目的规则：MAJOR 表示 ./include 下公开 C API 的破坏性变更，MINOR 表示向后兼容的功能、后端更新、模型支持或 API 新增，PATCH 表示不改 API 的缺陷修复。分发渠道列出预发布产物（Linux、macOS、Windows、Android、iOS）、Docker、Debian、Homebrew、conda-forge、MacPorts、Winget 以及面向 iOS / macOS 的 XCFramework。文中还写 ggml 后端可编译为动态库并在运行时按需加载；并称目前支持 150 种以上模型架构变体以及所有主流投机解码方法——这是项目自述，本机未清点。GitHub 仓库 ggml-org/llama.cpp 的 v1.0.0 发行版标记为正式版（非 pre-release），published_at 为 2026-11-13T10:20:19Z。本机未编译或运行该版本。
