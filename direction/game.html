    UE 5.8.4 加入 ASD Tool：可从已 cook 的 Windows 包生成 Advanced Shader Delivery 所需的 SODB

    Xbox 团队产品经理 Clint Woon 于 2026-11-18 发文称，自 Unreal Engine 5.8.4 热修复起，引擎提供 Advanced Shader Delivery（ASD）支持，并附上 Epic 新发布的指南。ASD 的背景是：Direct3D 12 游戏首次启动时，驱动会在创建 Pipeline State Object（PSO）时编译着色器，可能导致较长的首次加载和卡顿；ASD 把这项工作移出游戏，按 GPU 与驱动预先编译，并由商店随游戏分发结果。5.8.4 中的 ASD Tool（ASDTool）可从已 cook 的 Windows 包生成 ASD 所需的 State Object Database（SODB），它是独立命令行程序，不需要编辑器或正在运行的游戏。SODB 需提交到 Microsoft Store；文中转述 Epic 的说明：Epic Games Store 支持计划在 2027 年初提供。覆盖范围是 Windows D3D12 Shader Model 6 构建（PCD3D_SM6），光线追踪 PSO 不受支持。ASD 并不取代 PSO precaching 和随包 PSO 缓存，Epic 建议两者都保留。使用条件包括：必须从源码编译引擎（该工具没有预编译二进制），并且已为 Windows D3D12 SM6 构建准备好 PSO 缓存。本机未编译引擎，也未运行 ASDTool。

Last Week in Unreal：ue6-main 取消编辑器进程内 cook，项目级 cook 必须改走 cook commandlet

NVIDIA 于 2026-11-03 刊登对 Gaijin Entertainment 美术总监 Kirill Stupin 的访谈，介绍 War Thunder 如何把 DLSS 5（3D-Guided Neural Rendering）接入自研 Dagor Engine。文中说：11 月中旬的 Eagle's Shadow 大更会上线该功能；游戏此前已有 DLSS 4.5 Multi Frame Generation、Super Resolution、Ray Reconstruction、DLAA，以及 Reflex、光线追踪和路径追踪全局光照。NVIDIA 写 DLSS 5 作为图形管线的最后阶段运行，以引擎已渲染的帧和运动向量为基础增加光照与材质细节——这是厂商对功能的描述。Gaijin 团队说真正的难点不在文档（他们估计 NVIDIA 文档覆盖了约 95%），而在色彩空间：DLSS 5 在 sRGB 中工作，Dagor 与多数现代引擎一样在线性 HDR 中渲染；既要在 bloom、运动模糊、色差等后处理和 UI 之前评估 DLSS 5，又要喂给它带有玩家最终观感的 sRGB 图像。他们的做法是让色彩管理管线可逆，先做出「半最终」观感的 sRGB 图给 DLSS 5，再把 DLSS 5 造成的变化映射回线性 HDR；并在代表性场景上对照参考外观，调整模型和强度。访谈中的「高光/阴影更好、出现过去做不到的微对比度」「有组员一度以为换了渲染引擎」等是对方美术团队的主观评价，并非独立测评。给其他开发者的建议是：花时间按自己的美术方向去调。这是厂商访谈，本机未验证其画质或性能说法。
