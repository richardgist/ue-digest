Game Developer 根据 CEO Matt Webster 对 Gamesindustry.biz 的访谈，拆解 Galactic Racer 的 distributed development：最外层外包——给 brief、收交付、再集成，但仍要经营关系；中间 external development——把边界清晰的整块功能交给外部跨职能小队（例：照片模式），因 UE 便于「插槽式」接入；内层 co-dev——外部人员进站会/Slack，当作主团队延伸。GI.biz 称核心约 75 人，credits 约 1100 个专业角色（媒体转述）。文中 Steam 峰值约 1.8 万同在、评价 Mostly Positive、销售「healthy」等为采访/媒体数字，非本文核实。对中型 UE 项目，价值在于把「联研 / 外制 / 外包」三个词的边界说清楚，减少沟通错位。

Finding 1.4-second stalls by replaying play

团队用「环形缓冲记最近约 34 秒逐帧开销 + 标记按键 + 无窗口回放已记录对局」定位大城市爆炸后 0.2–1.4 秒卡顿。回放把最差物理步复现到约 836 ms，再逐项修：渲染移除钩子全表扫描、地形顶点哈希碰撞、爆炸范围查询、网格压缩等，并给出前后毫秒数；用世界状态 digest 确认修的是时间而非玩法。也记录了五条无效尝试，以及最终用更快冻结碎块（约 1.4 s）而不是减碎片数量的取舍。文末说明草稿由 Claude Code 据 changelog 起草、作者复核数字。
